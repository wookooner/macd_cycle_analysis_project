# =======================================================
# BTC 사이클 데이터 구조 명세서 (AI 파싱 및 관리용)
# =======================================================
# 이 파일은 프로젝트의 데이터 구조를 정의하는 중앙 소스입니다.
# 특징을 활성화/비활성화하려면 'Enabled' 값을 'true'/'false'로 수정하세요.

## 1. 최상위 데이터 구조 (Top-Level Structure)

| 컬럼명 | 데이터 타입 | 설명 |
| :--- | :--- | :--- |
| `cycle_id` | string | 각 사이클의 고유 ID (예: cycle_4h_20250828_001) |
| `timeframe` | string | 데이터의 시간 프레임 (예: 1h, 4h, 1d) |
| `start_date` | string | 사이클 시작 타임스탬프 (UTC) |
| `end_date` | string | 사이클 종료 타임스탬프 (UTC) |
| `cycle_type` | string | 사이클 타입 ('up' 또는 'down') |
| `duration_candles` | integer | 사이클의 전체 길이 (캔들 수) |
| `category` | string | 사이클의 상세 분류 (예: rising_positive) |
| `algorithm_used` | string | 사이클 감지에 사용된 알고리즘 이름 |
| `candle_data` | list of objects| 사이클에 포함된 모든 캔들의 상세 데이터 목록 |
| `cycle_features`| object | 모든 계산된 특징을 담는 중첩 객체 (아래 2번 참조) |

<br>

## 2. 사이클 특징 상세 정의 (Cycle Feature Definitions)
`cycle_features`에 포함되는 모든 특징을 카테고리별 테이블로 정의합니다.

### 📂 Shape (형태/구조)
*사이클의 기본적인 골격과 구조적 특성*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `duration_candles` | 사이클의 전체 길이 (캔들 수) | `calc_duration_candles` | int | `true` |
| `core_count` | 사이클 방향과 일치하는 핵심 캔들 수 | `calc_core_count` | int | `true` |
| `noise_count` | 허용된 노이즈(반대 방향) 캔들 수 | `calc_noise_count` | int | `true` |
| `direction_change` | 모멘텀 방향이 전환된 횟수 | `calc_direction_change` | int | `true` |
| `peak_price_position` | 사이클 내에서 최고가(high)를 기록한 캔들의 위치를 전체 사이클 길이로 나눈 값 | `calc_peak_price_position` | float | `true` |
| `trough_price_position` | 사이클 내에서 최저가(low)를 기록한 캔들의 위치를 전체 사이클 길이로 나눈 값 | `calc_trough_price_position` | float | `true` |

### 💪 Strength (강도/견고함)
*사이클의 추세가 얼마나 일관되고 견고했는지*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `direction_pct` | 핵심(core) 캔들의 비율 | `calc_direction_pct` | float | `true` |
| `hist_positive_ratio` | MACD 히스토그램이 양수였던 캔들의 비율 | `calc_hist_positive_ratio` | float | `true` |
| `price_up_ratio` | 가격이 상승한 (양봉) 캔들의 비율 | `calc_price_up_ratio` | float | `true` |
| `price_down_ratio` | 가격이 하락한 (음봉) 캔들의 비율 | `calc_price_down_ratio` | float | `true` |

### 🚀 Start (시작점 지표)
*사이클 시작 시점의 시장 상태*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `price` | 사이클 첫 캔들의 종가 | `calc_start_price` | float | `true` |
| `volume` | 사이클 첫 캔들의 거래량 | `calc_start_volume` | float | `true` |
| `rsi` | 사이클 첫 캔들의 RSI 값 | `calc_start_rsi` | float | `true` |
| `macd` | 사이클 첫 캔들의 MACD 값 | `calc_start_macd` | float | `true` |
| `macd_signal` | 사이클 첫 캔들의 MACD Signal 값 | `calc_start_macd_signal`| float | `true` |
| `hist` | 사이클 첫 캔들의 MACD Histogram 값 | `calc_start_hist` | float | `true` |

### 🏁 End (종료점 지표)
*사이클 종료 시점의 시장 상태*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `price` | 사이클 마지막 캔들의 종가 | `calc_end_price` | float | `true` |
| `volume` | 사이클 마지막 캔들의 거래량 | `calc_end_volume` | float | `true` |
| `rsi` | 사이클 마지막 캔들의 RSI 값 | `calc_end_rsi` | float | `true` |
| `macd` | 사이클 마지막 캔들의 MACD 값 | `calc_end_macd` | float | `true` |
| `macd_signal` | 사이클 마지막 캔들의 MACD Signal 값 | `calc_end_macd_signal`| float | `true` |
| `hist` | 사이클 마지막 캔들의 MACD Histogram 값 | `calc_end_hist` | float | `true` |

### 📈 Change (시작-종료 변화량)
*사이클 시작과 끝을 비교한 순수 변화량*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `price_pct` | 시작가 대비 종료가의 등락률 | `calc_price_change_pct` | float | `true` |
| `rsi` | RSI 값의 변화량 | `calc_rsi_change` | float | `true` |
| `macd` | MACD 값의 변화량 | `calc_macd_change` | float | `true` |
| `macd_signal` | MACD Signal 값의 변화량 | `calc_macd_signal_change` | float | `true` |
| `hist` | MACD Histogram 값의 변화량 | `calc_macd_histogram_change` | float | `true` |

### 🎢 Volatility (내부 변동성/극값)
*사이클 진행 중 발생한 가격 움직임의 크기 및 변동성*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `max_high_pct` | 시작가 대비 사이클 내 최고가의 상승률 | `calc_max_high_pct` | float | `true` |
| `max_loss_pct` | 시작가 대비 사이클 내 최저가의 하락률 | `calc_max_loss_pct` | float | `true` |
| `max_intraday_high_pct`| 캔들 내 발생한 최대 상승 변동률 | `calc_max_intraday_high_pct`| float | `true` |
| `max_intraday_loss_pct`| 캔들 내 발생한 최대 하락 변동률 | `calc_max_intraday_loss_pct`| float | `true` |
| `avg_true_range` | 캔들의 평균 ATR 값 (평균 변동폭) | `calc_avg_true_range` | float | `true` |
| `price_change_deviation`| 가격 변동률의 표준편차 | `calc_price_change_deviation`| float | `true` |

### 🏦 Aggregate (전체 집계)
*사이클 전체 기간의 데이터를 합산한 값*

| Feature | Description | Calculator | Type | Enabled |
| :--- | :--- | :--- | :--- | :--- |
| `volume` | 사이클 내 모든 캔들의 거래량 총합 | `calc_all_volume` | float | `true` |
